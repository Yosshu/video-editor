# 05. 実装ロードマップ

[02-requirements.md](02-requirements.md) の機能を、どの順序でどう実装するかを定める。

## 1. 順序の考え方

1. **土台を先に固める**：プロジェクトのデータ構造と保存形式は全機能の土台になる。後から変えるとすべてに影響するため最初に決める（ただし移行の仕組みを用意して変更できるようにしておく）。
2. **難しいところを早く通す**：ブラウザでの動画デコード・同期再生・書き出しは最大の技術リスク。Phase 0 で小さく検証し、Phase 3 までに「取り込み → 編集 → 書き出し」を一通り通す。
3. **静止素材 → 動画・音声の順に作る**：画像・テキスト・図形でエディタと描画の骨格を作ってから動画を載せると、問題の切り分けがしやすい。
4. **最小限でも使える状態を早く公開する**：Phase 3 完了で v0.1 として公開し、以降は機能を積み増す。
5. **表現力 → 効率 → 拡張の順**：アニメーション・エフェクト・制御オブジェクトで「作り込める」ようにしてから、編集効率と拡張性を高める。

## 3. 各フェーズの内容

### Phase 0：開発基盤と技術検証

**目的**：開発を回す仕組みを整え、ブラウザで動画編集が成り立つことを小さく確かめる。

- [ ] リポジトリ設定
  - [ ] `main` ブランチを作成してデフォルトブランチにする
  - [ ] Pages の Source が「GitHub Actions」であることを確認（設定済み）
  - [ ] `github-pages` 環境のデプロイ許可ブランチに `main` が含まれることを確認
- [ ] Vite + React + TypeScript の雛形、ESLint / Prettier、Vitest、Playwright
- [ ] GitHub Actions：PR で lint・型チェック・テスト・ビルド、`main` への push で Pages にデプロイ
- [ ] 仮の画面を `https://yosshu.github.io/video-editor/` に公開
- [ ] 対応ブラウザの判定と、非対応時の案内表示
- [ ] 技術検証（使い捨てのコードで行い、結果を docs に記録）
  - [ ] MP4 を Worker でデコードし、WebGL2 で 30fps 表示できるか
  - [ ] 任意フレームへのシーク速度
  - [ ] 10 秒の映像＋音声を MP4 / WebM に書き出せるか
  - [ ] Chrome / Edge / Firefox / Safari で使えるコーデックの一覧（機能検出で取得）
  - [ ] File System Access API・OPFS での保存と再読込

**完了条件**：Pages の URL で雛形が表示され、CI が通り、技術検証の結果がまとまっている。

### Phase 1：データ構造とエディタの骨格

**目的**：レイヤー型タイムラインの基本操作と、保存・再開の流れを完成させる。

- [ ] `core/model`：Project / Scene / Layer / TimelineObject の型
- [ ] `core/params`：パラメータ定義の仕組み（型・範囲・既定値）
- [ ] `core/schema`：Zod スキーマ、編集ファイルの検証、`formatVersion` と移行の枠組み
- [ ] `core/commands`：編集コマンドと元に戻す/やり直し
- [ ] 画面レイアウト：メニュー、素材一覧、プレビュー、タイムライン、設定パネル（大きさ変更可）
- [ ] タイムライン
  - [ ] レイヤー見出し（名前・表示/非表示・ロック）、時間目盛り、拡大縮小・スクロール
  - [ ] オブジェクトの追加・移動・長さ変更・レイヤー間移動（衝突判定）
  - [ ] スナップ、分割、削除、複数選択、コピー/貼り付け
  - [ ] 再生ヘッドのドラッグでシーク
- [ ] 設定パネル：パラメータ定義から入力欄（数値＋スライダー、色、文字列、選択肢）を自動生成
- [ ] レンダラー（WebGL2）：座標変換、不透明度、通常合成
- [ ] オブジェクト：画像、テキスト、図形、単色
- [ ] プレビュー：再生/停止、コマ送り、ドラッグで位置移動
- [ ] 保存：`.vedproj` の保存・上書き保存・読み込み、自動保存と復元
- [ ] キーボードショートカット（再生、分割、削除、元に戻す 等）
- [ ] 単体テスト：衝突判定、分割、スナップ、保存 → 読込の往復

**実装のポイント**

- タイムラインの操作は「ドラッグ中は見た目だけ動かし、離したときにコマンドを1回発行する」形にし、履歴が細切れにならないようにする。
- レンダラーは最初から「オブジェクトごとのバッファ → シーンへ合成」の構造にしておき、Phase 5 のエフェクト追加で作り直さずに済むようにする。

**完了条件**：画像とテキストを複数レイヤーに重ねて配置し、保存 → ページ再読込 → 編集ファイルを投下して同じ状態に戻る。

### Phase 2：動画・音声

**目的**：動画と音声を扱い、映像と音がずれずに再生できるようにする。

- [ ] 素材の取り込み（ドラッグ＆ドロップ・ファイル選択）、Mediabunny でのメタデータ解析
- [ ] 素材一覧（サムネイル・長さ・解像度・コーデック表示、タイムラインへドラッグ）
- [ ] MediaWorker：デコード、シーク、フレームキャッシュ、先読み
- [ ] 動画オブジェクト：再生開始位置・再生速度・ループ
- [ ] 音声：デコード、ミックス、AudioContext を基準時計にした同期再生
- [ ] 音量・パン、フェードイン/アウト（映像・音声）
- [ ] プレビュー画質の切り替え（等倍・1/2・1/4）
- [ ] タイムラインのサムネイル・波形表示
- [ ] 素材の再リンク：指紋の計算、ファイルハンドルの保存、不足素材ダイアログ、フォルダ投下での自動照合
- [ ] 非対応コーデックの案内

**実装のポイント**

- 再生用（間に合わなければ飛ばす）と、書き出し用（必ず待つ）でフレームの取得方法を分けられる API にしておく。
- `VideoFrame` の `close()` 漏れは GPU メモリ不足につながるため、所有者を明確にしてテストで検出する。

**完了条件**：2本の動画と BGM を並べて音ズレなく再生でき、ページを開き直しても素材が復元される。

### Phase 3：書き出し → v0.1 公開

**目的**：作った動画を一般的なファイルとして書き出せるようにし、最初の版を公開する。

- [ ] 書き出しダイアログ：形式（MP4 / WebM）、解像度、ビットレート/品質、範囲
- [ ] 環境で使えるコーデックだけを選択肢に表示
- [ ] ExportWorker：1フレームずつ描画 → `VideoEncoder` → Mediabunny で多重化
- [ ] 音声：`OfflineAudioContext` でミックス → `AudioEncoder`
- [ ] File System Access API への直接書き込み（その他の環境はダウンロード）
- [ ] 進捗・残り時間・キャンセル
- [ ] 現在フレームの PNG 保存、WAV 書き出し
- [ ] 再生範囲・書き出し範囲の指定
- [ ] E2E テスト：取り込み → 配置 → 書き出し → ファイルの長さとフレーム数を検証
- [ ] README に使い方を記載し、v0.1 として公開

**完了条件**：書き出した MP4 が一般的な動画プレイヤーで再生でき、プレビューと見た目が一致する。

### Phase 4：アニメーション

- [ ] キーフレームのデータ構造と補間処理（直線・瞬間・イージングプリセット・ベジェ）
- [ ] 設定パネルでのキー追加/削除、前後のキーへの移動
- [ ] 中間点（全パラメータの同時刻にキー）の追加・削除・移動
- [ ] タイムライン上のキー表示とドラッグ
- [ ] イージング曲線の簡易エディタ
- [ ] プレビュー上のハンドル（移動・拡大・回転）、グリッド・セーフエリア（表示の拡大縮小は Phase 7 へ）
- [ ] 音量・パンのキーフレーム

**完了条件**：テキストがイージング付きでスライドインし、フェードアウトする動画を作って書き出せる。

### Phase 5：エフェクトと合成 → v0.2

- [ ] エフェクト定義の仕組み（パラメータ定義 ＋ シェーダー、描画範囲の拡張）
- [ ] エフェクトの追加・並べ替え・有効/無効・削除の UI
- [ ] 基本エフェクト：色調整、単色化、ぼかし、境界ぼかし、モザイク、シャープ、縁取り、ドロップシャドウ、発光、グロー、クリッピング、図形マスク、クロマキー、カラーキー、ルミナンスキー
- [ ] 合成モード一式
- [ ] フィルタオブジェクト、上のオブジェクトでクリッピング
- [ ] 切り替え効果（クロスフェード・ワイプ・スライド）
- [ ] 演出プリセット（登場・退場・震える 等）
- [ ] 描画テスト（基準画像との比較）

### Phase 6：高度なレイヤー制御 → v0.3

- [ ] 複数シーン、シーンオブジェクト（入れ子・循環参照の禁止）
- [ ] グループ制御、時間制御、部分フィルタ
- [ ] 3D：Z 座標、X/Y 軸回転、カメラ制御（透視投影・奥行き・光源）
- [ ] 文字ごとのアニメーション、1文字ずつ表示
- [ ] 直前までの合成結果を素材にするオブジェクト

### Phase 7：音声強化と編集効率 → v0.4

- [ ] 音声エフェクト（イコライザー・コンプレッサー・ディレイ/エコー・リバーブ）、レベルメーター
- [ ] リップル削除、空白の削除、マーカー、BPM グリッド
- [ ] レイヤーの挿入・削除、前のオブジェクトの値の引き継ぎ
- [ ] オブジェクト・エフェクト設定のプリセット
- [ ] ショートカットのカスタマイズ、全画面プレビュー
- [ ] 特殊な変化方法（ランダム・反復・振動）、追加エフェクト、音声波形の可視化
- [ ] プロジェクト設定の後からの変更

### Phase 8：拡張と配布 → v1.0

- [ ] 素材同梱パッケージ（`.vedpack`）
- [ ] PWA（オフライン動作、インストール、拡張子の関連付け）
- [ ] 英語 UI、テーマ切り替え
- [ ] 他のパラメータを参照する式、ユーザー定義シェーダー（安全な範囲で実行）
- [ ] LUT、アニメーション画像・連番画像の入力、GIF・連番・透過動画の出力、字幕ファイルの読み込み、パーティクル
- [ ] 性能改善：プレビュー描画の Worker 化、WebGPU 版レンダラーの検討

## 4. 進め方のルール

- 1つの機能（またはその一部）ごとにブランチを切り、Pull Request で `main` に取り込む。
- `main` は常に公開可能な状態を保つ（push すると自動で公開される）。
- 仕様を変えたら `docs/` も同じ Pull Request で更新する。
- 編集ファイルの形式を変えるときは `formatVersion` を上げ、移行関数とテストを追加する。

## 5. リスクと対策

| リスク                                              | 影響                               | 対策                                                                                                  |
| --------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------- |
| ブラウザ・OS によって読み書きできるコーデックが違う | 素材が読めない、書き出せない       | 機能検出で使える形式だけ提示。読めない素材は理由と変換方法を案内。将来 WebAssembly のデコーダーを検討 |
| GPU・メモリ不足                                     | 4K 素材や多レイヤーで落ちる        | メモリ量で上限を決めたキャッシュ、`VideoFrame` の確実な解放、プレビュー画質の自動調整                 |
| 音ズレ                                              | 再生・書き出しで映像と音が合わない | 音声を基準時計にする。書き出しはサンプル単位で時刻を計算                                              |
| 可変フレームレートの素材                            | フレームの重複・欠落               | タイムスタンプ基準で最も近いフレームを選ぶ                                                            |
| 大きなファイルの書き出し                            | メモリに載らない                   | Chromium 系はファイルへ直接書き込み。他は上限を案内                                                   |
| 編集ファイルの互換性                                | 古いファイルが開けない             | `formatVersion` と段階的な移行、移行テスト                                                            |
| PC ごとにフォントが違う                             | 文字の見た目が変わる               | フォント名を保存し、ない場合は代替フォントと警告。パッケージにフォントを同梱                          |
| GitHub Pages で HTTP ヘッダーを設定できない         | `SharedArrayBuffer` が使えない     | 使わない前提で設計（WebCodecs・WebGL2・Web Audio はヘッダー不要）                                     |
