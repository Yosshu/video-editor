# 02. 要件定義（実装する機能）

[01-feature-survey.md](01-feature-survey.md) の調査をもとに、本アプリで実装する機能と優先度を定める。

## 1. 目的とターゲット

- **目的**：インストール不要で、ブラウザだけで「レイヤーを重ねて作り込む」動画編集ができる Web アプリを作る。
- **ターゲット**
  - 解説動画・ゲーム実況・MAD・モーション素材など、テキストや画像を重ねて演出を作り込みたい人
  - PC にソフトを入れられない／入れたくない人、OS を問わず同じ環境で編集したい人
- **公開先**：GitHub Pages（`https://yosshu.github.io/video-editor/`）

## 2. 前提と制約

- サーバーを持たない静的サイト。処理はすべて利用者のブラウザ内で行い、素材を外部に送信しない。
- 主対象は PC 版の Chrome / Edge。Firefox・Safari は機能検出で動く範囲を広げていく。
- スマートフォン・タブレットでの編集は当面対象外。
- ブラウザは素材ファイルの「パス」を保持できないため、編集ファイルを開き直すときは素材の再リンクが必要になる場合がある（[04-project-file-format.md](04-project-file-format.md)）。

## 3. 用語

| 用語                 | 意味                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| プロジェクト         | 1つの作品の編集データ全体。設定・素材一覧・シーンを持つ                                          |
| シーン               | 1本のタイムライン。プロジェクトは1つ以上のシーンを持ち、シーンを別のシーンに素材として配置できる |
| レイヤー             | タイムラインの横一列。番号（1〜）で識別する                                                      |
| オブジェクト         | レイヤー上の時間区間に置く要素。メディアオブジェクトと制御オブジェクトがある                     |
| メディアオブジェクト | 動画・画像・音声・テキスト・図形など、それ自体が描画・発音されるもの                             |
| 制御オブジェクト     | フィルタ・グループ制御・時間制御・カメラ制御など、他のレイヤーに作用するもの                     |
| パラメータ           | オブジェクトやエフェクトが持つ数値・色・文字列などの設定値                                       |
| エフェクト           | オブジェクトに追加する加工処理（フィルタ効果）。1つのオブジェクトに複数を順に適用できる          |
| キーフレーム         | パラメータの値を時間ごとに指定する点。点と点の間は補間方法に従って変化する                       |
| 素材（アセット）     | 読み込んだ動画・画像・音声・フォントのファイル                                                   |
| 編集ファイル         | プロジェクトを保存したファイル（[04-project-file-format.md](04-project-file-format.md)）         |

## 4. タイムラインの基本仕様

### 4.1 時間とレイヤー

- 時間の単位は**フレーム（整数）**。フレームレートはプロジェクト設定で決める（例：30fps、29.97fps、60fps）。
- レイヤーは 1 から始まる番号で表し、初期表示は 100 レイヤー程度、必要に応じて増やす。
- 同じレイヤーの同じ時間に2つのオブジェクトは置けない（移動時は衝突しない位置に調整する）。

### 4.2 描画順（重なり順）

- **レイヤー番号の小さい順に描画し、番号が大きいレイヤーほど手前に表示する**（タイムライン上で下にあるレイヤーほど手前）。
- 各オブジェクトは「素材を描く → オブジェクトのエフェクトを上から順に適用 → 座標・拡大率・回転・不透明度・合成モードに従って画面に合成」の順で処理する。

### 4.3 制御オブジェクトの作用範囲

| 制御オブジェクト                                     | 作用範囲                                                  |
| ---------------------------------------------------- | --------------------------------------------------------- |
| フィルタオブジェクト                                 | 自分より上（番号が小さい）のレイヤーをすべて合成した結果  |
| グループ制御                                         | 自分より下の、指定した数のレイヤー上のオブジェクト        |
| 時間制御                                             | 自分より下の、指定した数のレイヤーの時間の流れ            |
| カメラ制御                                           | 自分より下のレイヤーで「3D 対象」に設定されたオブジェクト |
| 部分フィルタ                                         | 自分より上のレイヤーを合成した結果のうち、指定した範囲    |
| 上のオブジェクトでクリッピング（オブジェクトの設定） | 直上のレイヤーにある同時刻のオブジェクトの形状            |

### 4.4 座標系

- 画面中央を原点 (0, 0) とし、X は右がプラス、Y は下がプラス、Z は奥がプラス。
- 回転は度数法、時計回りがプラス。拡大率は % (100 = 等倍)。不透明度は 0〜100%（100 = 不透明）。

## 6. 非機能要件

| ID     | 項目           | 目標                                                                                                                            |
| ------ | -------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| NFR-01 | 対応ブラウザ   | PC 版 Chrome / Edge の最新版を主対象。Firefox（デスクトップ）と Safari 26 以降は、機能検出で使える範囲で動作させる              |
| NFR-02 | プレビュー性能 | 1080p / 30fps で、動画3本＋テキスト・画像数個の重ね合わせを、内蔵 GPU の一般的なノート PC でプレビュー画質 1/2 以上で実時間再生 |
| NFR-03 | 書き出し性能   | 1080p で実時間の 1〜3 倍程度の時間で書き出し（ハードウェアエンコーダー利用時）                                                  |
| NFR-04 | 扱える素材     | 1ファイル数 GB まで。ファイル全体をメモリに読み込まず、必要な部分だけ読む                                                       |
| NFR-05 | 作品の長さ     | 60 分程度まで                                                                                                                   |
| NFR-06 | プライバシー   | 素材・編集内容をネットワークに送信しない。アクセス解析も当面入れない                                                            |
| NFR-07 | データ保全     | 自動保存。古いバージョンで保存した編集ファイルを新しいバージョンで開ける（後方互換）                                            |
| NFR-08 | 安全性         | 読み込むファイルはすべて形式を検証してから使う。編集ファイルの内容をプログラムとして実行しない                                  |
| NFR-09 | 初回表示       | 初回ダウンロード量を圧縮後 2MB 程度以下に抑え、重い機能は必要になった時点で読み込む                                             |
| NFR-10 | 操作性         | 主要操作はキーボードでも行える。文字と背景のコントラストを十分に取る                                                            |

## 7. 当面やらないこと

- アカウント、サーバー保存、共同編集
- AI 機能（自動字幕・背景除去など）。将来、ブラウザ内で完結する推論として検討する
- スマートフォン向けの編集 UI
- ネイティブコードのプラグイン
- ブラウザがデコードできない形式（ProRes など）の直接読み込み。将来 WebAssembly のデコーダーを検討する
