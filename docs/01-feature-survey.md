# 01. 動画編集ソフトの機能調査

本アプリで何を実装すべきかを決めるために、一般的な動画編集ソフトが備えている機能を洗い出す。
特定の製品名は記載せず、ソフトの「タイプ」で整理する。

## 1. 調査対象（ソフトのタイプ）

| 記号 | タイプ | 特徴 |
|---|---|---|
| **L** | レイヤー型の合成エディタ | 1本のタイムラインに番号付きのレイヤーを多数重ね、各オブジェクトにパラメータ・アニメーション・エフェクトを積んで作り込む。軽量・無料のデスクトップソフトに多く、スクリプトやプラグインで拡張する文化がある。**本アプリの主な手本** |
| **N** | プロ向けノンリニア編集ソフト | 映像トラックと音声トラックを分けたトラック型タイムライン。カット編集の効率、色の調整、音声ミキシング、素材管理に強い |
| **M** | モーショングラフィックス／合成ソフト | キーフレームとグラフエディタ、親子付け、3D カメラ、式による精密なアニメーションに強い |
| **S** | 簡易編集アプリ・ブラウザ編集サービス | テンプレート、ワンタップのエフェクト、自動字幕などの AI 機能、SNS 向け書き出し。直感的だが細かい制御は限定的 |

補足：上記のほかに、キャラクター立ち絵の口パク・音声合成による読み上げ・字幕の自動同期に特化した「解説動画特化ツール」というタイプもある。

### 凡例

- ◎：標準的に備える
- ○：一部のソフトが備える／限定的
- △：プラグイン等の追加で対応、またはまれ
- –：ほぼない

## 3. タイプごとの強みと弱み

| タイプ | 強み | 弱み |
|---|---|---|
| L：レイヤー型 | 自由な重ね合わせと作り込み、軽さ、スクリプトによる拡張、制御オブジェクトの柔軟さ | 素材管理・カット編集の効率機能が弱い、標準の出力形式が少ない、学習コストがやや高い |
| N：プロ向け NLE | 長尺のカット編集の効率、色と音の品質、素材管理 | 重い、高価なものが多い、演出の作り込みは専用ソフト頼み |
| M：合成ソフト | 精密なアニメーションと合成 | 長尺の編集には不向き、重い |
| S：簡易・Web | 直感的、テンプレートと AI、インストール不要（Web 版） | 細かい制御ができない、有料機能・透かし、素材をサーバーにアップロードする必要があるものが多い |

## 4. 本アプリへの示唆

1. **核はレイヤー型**にする。番号付きレイヤー、オブジェクトごとのパラメータとエフェクトの積み重ね、制御オブジェクト（フィルタ・グループ・カメラ・時間）という仕組みを中心に設計する。
2. **簡易・Web 型の良さ**を取り入れる。インストール不要、分かりやすい UI、演出プリセット、書き出しが簡単（MP4 をそのまま出せる）。
3. **NLE の効率機能**（素材の再接続、リップル削除、マーカー）は中盤以降に追加する。
4. **合成ソフトのアニメーション機能**（イージング・グラフ編集）は、キーフレーム実装時に取り入れる。
5. **ブラウザならではの強み**を打ち出す。
   - インストール不要・OS を問わない
   - 素材をサーバーに送らない（すべて手元のブラウザ内で処理）
   - URL を開けばすぐに最新版が使える
6. **ブラウザならではの制約**を前提に設計する（詳細は [03-architecture.md](03-architecture.md)）。
   - 読み書きできるコーデックがブラウザ・OS に依存する
   - メモリと GPU の制約が厳しい
   - ローカルファイルへのアクセスが制限される（パスで素材を参照できない）
   - 使えるフォントが環境により異なる
