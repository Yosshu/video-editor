# 04. 編集ファイルの形式

編集内容を保存し、後でブラウザに投下すると続きから編集できるようにするためのファイル形式を定める。

## 1. 方針

- **独自形式・テキスト（JSON）**：人が読めて差分も取りやすく、バージョン間の移行処理も書きやすい。
- **素材は埋め込まない（既定）**：動画素材は数 GB になることがあるため、編集ファイルには素材の「識別情報」だけを書く。素材ごと持ち運びたい場合のために、別途「素材同梱パッケージ」を用意する。
- **バージョン番号を持つ**：将来の形式変更に備え、古いファイルを新しいアプリで必ず開けるようにする。

## 2. 拡張子（仮）

| 種類               | 拡張子         | 中身                                | 用途                                                    |
| ------------------ | -------------- | ----------------------------------- | ------------------------------------------------------- |
| 編集ファイル       | **`.vedproj`** | JSON（UTF-8）                       | 通常の保存。軽い（数 KB〜数 MB）                        |
| 素材同梱パッケージ | **`.vedpack`** | ZIP（編集ファイル＋素材＋フォント） | 別の PC やブラウザへの持ち運び、バックアップ（Phase 8） |

- 拡張子は独自に決められる。`ved` は "video editor" の略。アプリ名が決まったらそれに合わせて変更してよい（形式が確定する Phase 1 までに決める）。
- 既存の有名ソフトと重複しない名前を選ぶ。
- PWA 化（Phase 8）すると、インストールしたアプリに拡張子を関連付けて、ダブルクリックで開けるようにできる（Chromium 系の File Handling API）。

## 3. 続きから編集する3つの方法

| 方法                               | 使う場面                               | 素材の扱い                                                                             |
| ---------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------- |
| ① 自動保存から復元                 | 同じブラウザでページを開き直したとき   | ファイルハンドル（Chromium 系）または OPFS のコピーから自動で復元                      |
| ② 編集ファイル（`.vedproj`）を投下 | 保存した作品を開く、別のブラウザで開く | 復元できない素材は一覧表示し、素材ファイル（またはフォルダ）を投下してもらって自動照合 |
| ③ パッケージ（`.vedpack`）を投下   | 別の PC へ持ち運ぶ                     | 素材が同梱されているので何もしなくてよい                                               |

### 3.1 素材の照合ルール

ブラウザはファイルのパスを取得できないため、次の情報で素材を特定する。

1. **指紋（fingerprint）**：ファイルサイズ ＋ 先頭 1MiB と末尾 1MiB の SHA-256。数 GB のファイルでも一瞬で計算できる
2. ファイル名 ＋ ファイルサイズ
3. ファイル名のみ（確認ダイアログを出す）

照合の順序：

1. ブラウザ内に保存済みのファイルハンドル・OPFS コピーを探す
2. 見つからない素材を一覧表示し、利用者にファイルまたはフォルダを投下してもらう
3. 投下されたファイルを上記 1 → 2 → 3 の順に照合して自動で割り当てる
4. 最後まで見つからない素材は「不足素材」として赤く表示し、編集は続けられるようにする（後から差し替え可能）

## 4. 編集ファイルの構造

### 4.1 全体

```jsonc
{
  "format": "vedproj", // 形式の識別子
  "formatVersion": 1, // 形式のバージョン（整数）
  "generator": { "name": "video-editor", "version": "0.1.0" },
  "createdAt": "2026-10-21T12:00:00Z",
  "updatedAt": "2026-10-21T12:34:56Z",

  "settings": {
    "width": 1920,
    "height": 1080,
    "fps": { "num": 30, "den": 1 }, // 29.97fps は { "num": 30000, "den": 1001 }
    "sampleRate": 48000,
    "audioChannels": 2,
    "backgroundColor": "#000000",
  },

  "assets": [/* 素材の一覧（4.2） */],
  "rootSceneId": "sc_main",
  "scenes": [/* シーンの一覧（4.3） */],
}
```

### 4.2 素材（assets）

```jsonc
{
  "id": "as_7f3a",
  "kind": "video", // video | image | audio | font
  "name": "opening.mp4", // 元のファイル名
  "mimeType": "video/mp4",
  "size": 52428800, // バイト数
  "lastModified": 1760000000000,
  "fingerprint": "ht1:9f2c…", // 先頭・末尾の SHA-256（3.1）
  "durationSec": 12.5,
  "video": { "width": 1920, "height": 1080, "codec": "avc1.640028", "frameRate": 29.97 },
  "audio": { "sampleRate": 48000, "channels": 2, "codec": "mp4a.40.2" },
}
```

### 4.3 シーン・レイヤー・オブジェクト

```jsonc
{
  "id": "sc_main",
  "name": "メイン",
  "width": 1920,
  "height": 1080,
  "layers": [
    // 既定値から変更のあるレイヤーだけ記録
    { "index": 1, "name": "背景" },
    { "index": 3, "name": "字幕", "locked": true },
  ],
  "objects": [
    {
      "id": "ob_01",
      "type": "video",
      "layer": 1, // 1 始まり
      "start": 0, // 開始フレーム
      "length": 300, // 長さ（フレーム）
      "assetId": "as_7f3a",
      // 既定値から変更したパラメータだけを記録する（4.4）
      "params": { "offset": 2.5, "speed": 100, "volume": 80, "fadeOut": 0.5 },
      "effects": [
        {
          "id": "fx_01",
          "type": "colorAdjust",
          "enabled": true,
          "params": { "brightness": 110, "saturation": 120 },
        },
      ],
    },
    {
      "id": "ob_02",
      "type": "text",
      "layer": 3,
      "start": 30,
      "length": 120,
      "params": {
        "text": "タイトル",
        "font": "Noto Sans JP",
        "size": 96,
        "outlineWidth": 6,
        "y": {
          "keys": [
            // キーフレーム（4.4）
            { "t": 0, "v": 200, "ease": "easeOutCubic" },
            { "t": 20, "v": 0 },
          ],
        },
        "opacity": {
          "keys": [
            { "t": 0, "v": 0, "ease": "linear" },
            { "t": 10, "v": 100 },
          ],
        },
      },
      "effects": [],
    },
  ],
}
```

- `type` の種類
  - メディア：`video` `image` `audio` `text` `shape` `solid`、`scene`（別のシーンを素材にする。`params.sceneRef` にシーン ID）、`framebuffer`（それまでに描いた画面を素材にする）
  - 制御：`filter`（上のレイヤー全体にエフェクト）、`partialFilter`（範囲の中だけエフェクト）、`group`（グループ制御）、`timeControl`（時間制御）、`camera`（カメラ制御）。制御オブジェクトの `range` は作用する下のレイヤー数（0 で下のすべて）
- `effects` はオブジェクトに上から順に適用するエフェクト。`type` の種類：`colorAdjust`（色調補正）`monochrome`（単色化）`blur`（ぼかし）`edgeBlur`（境界ぼかし）`mosaic`（モザイク）`sharpen`（シャープ）`glow`（発光）`outline`（縁取り）`dropShadow`（ドロップシャドウ）`crop`（クリッピング）`mask`（図形マスク）`chromaKey` `colorKey` `lumaKey`（キー抜き）。エフェクトのパラメータもキーフレームで変化させられる（形式はオブジェクトのパラメータと同じ）。知らない種類のエフェクトは描画せずにそのまま残す。
- パラメータはオブジェクトの種類ごとに定義されている（`src/core/objects/definitions.ts`）。省略したパラメータは既定値とみなす（ファイルを小さく保ち、既定値の変更にも追従しやすくする）。
- 主なパラメータ
  - 配置：`x` `y`（px、画面中央が原点）、`scale`（%）、`rotation`（度）、`opacity`（%）、`flipH` `flipV`、`blend`（合成モード）、`clipUpper`（上のオブジェクトでクリッピング）
  - 3D：`z`（奥行き、px）、`rotX` `rotY`（度）
  - 登場・退場：`enterType` `exitType`（`fade` `slideLeft` `zoom` `wipeLeft` `circle` など）、`enterDuration` `exitDuration`（秒）
  - フェード：`fadeIn` `fadeOut`（秒）
  - 動画・音声：`offset`（素材の再生開始位置、秒）、`speed`（%）、`loop`、`volume`（%）、`pan`（-100〜100）
  - テキスト：`text` `font` `size` `color` `bold` `italic` `align` `lineHeight` `letterSpacing` `outlineWidth` `outlineColor` `shadow` `typeSpeed`（1 文字ずつ表示）など
  - 図形：`shape` `width` `height` `color` `strokeWidth` `cornerRadius` `starInner`
- シーンの長さは、最後のオブジェクトの終了位置で決まる（保存しない）。

### 4.4 パラメータとキーフレームの表し方

- 変化しない値：数値・文字列をそのまま書く（`"x": 0`）。
- 変化する値：`{ "keys": [...] }` で表す。
  - `t`：オブジェクトの開始からの相対フレーム
  - `v`：値
  - `ease`：その点から次の点までの変化の仕方
    - `hold`（瞬間切り替え）、`linear`（直線）
    - `easeIn*` / `easeOut*` / `easeInOut*` のプリセット
    - `{ "bezier": [x1, y1, x2, y2] }`（自由なイージング曲線）
    - 将来：`random`・`repeat` などの特殊な変化を追加
- オブジェクト全体を区切る「中間点」は、すべてのパラメータの同じ時刻にキーを打つ操作として UI で提供する（データ上はパラメータごとのキーに統一）。

### 4.5 時間の表し方

- 時間はすべて **整数のフレーム番号**。フレームレートは `settings.fps` に有理数で持つ（29.97fps などの誤差を出さないため）。
- フレームレートを後から変更した場合は、すべての時間を換算して丸める。
- 素材内の時刻（`offset`）は素材側のフレームレートが異なりうるため秒（小数）で持つ。

## 5. バージョン管理と移行

- `formatVersion` は互換性のない変更をするたびに 1 増やす。
- 読み込み時の処理：
  1. `format` が `vedproj` であることを確認
  2. `formatVersion` が古ければ、`v1 → v2 → v3 …` と1段ずつ移行関数を適用
  3. 新しすぎる（アプリより新しい）場合は警告を出し、可能な範囲で読み込む
  4. Zod スキーマで検証。知らない項目は削除せず保持し、再保存で失われないようにする
- 移行関数ごとに「旧形式のサンプル → 新形式」のテストを用意する。

## 6. 素材同梱パッケージ（`.vedpack`）

```
example.vedpack（ZIP）
├── mimetype            # "application/x-vedpack"（無圧縮・先頭に配置）
├── project.vedproj     # 編集ファイル（4 と同じ形式）
├── media/
│   ├── as_7f3a.mp4     # 素材（動画は圧縮済みなので無圧縮で格納）
│   └── as_91bc.png
└── fonts/
    └── as_0c11.ttf
```

- ZIP は書き出し中もメモリに全体を載せないストリーム方式で作る（Chromium 系では直接ファイルへ書き込む）。
- 読み込み時は、素材を OPFS に展開してから使う。

## 7. 安全性

- 編集ファイル・パッケージは信頼できない入力として扱い、必ずスキーマ検証してから使う。
- 編集ファイル内の文字列をプログラムとして実行しない。将来、式やユーザー定義シェーダーを入れる場合は、実行範囲を限定した仕組みで評価する。
- ファイルサイズ・オブジェクト数・ネストの深さに上限を設け、異常なファイルでブラウザが固まらないようにする。
