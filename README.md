# video-editor

ブラウザだけで動く、レイヤー型の動画編集 Web アプリです（開発中）。

- 公開予定 URL：https://yosshu.github.io/video-editor/
- 主な動作環境（予定）：PC 版 Chrome / Edge の最新版（Firefox・Safari は順次対応）
- 素材はすべてブラウザ内で処理し、サーバーへアップロードしません

## できるようにすること

- 縦に積み重なる **レイヤー** と横方向の **時間** でできたタイムラインに、動画・画像・音声・テキスト・図形を重ねて編集
- オブジェクトごとに位置・拡大率・回転・不透明度などのパラメータ、キーフレームによるアニメーション、エフェクトを設定
- フィルタ・グループ制御・時間制御・カメラ制御などの「制御オブジェクト」で、複数レイヤーにまとめて効果をかける
- 編集内容を **編集ファイル（`.vedproj`、仮）** として保存し、後でブラウザに投下すると続きから編集できる
- MP4 / WebM で書き出し（ブラウザのハードウェアエンコーダーを利用）

## 使い方

1. 動画・画像・音声ファイルを、左の「素材」またはタイムラインにドラッグ＆ドロップします。
2. タイムラインの空いている場所を右クリックすると、テキスト・図形・単色を追加できます。
3. オブジェクトを選ぶと、右の「設定」で位置・大きさ・回転・不透明度・音量などを変更できます。プレビュー上でドラッグして動かしたり、四隅で拡大、上の丸で回転したりもできます。
4. 値の横の ◇ を押すとその時刻にキーフレームが打たれ、別の時刻で値を変えると自動でキーが増えます（「変化」で加速・減速などを選べます）。「中間点を追加」で、動いているすべての値に同じ時刻のキーを打てます。
5. 「設定」の下の「エフェクトを追加」で、ぼかし・縁取り・影・発光・色調補正・クロマキーなどを重ねられます。タイムラインの右クリックから「フィルタ」を置くと、それより上のレイヤー全体にエフェクトがかかります。「上のオブジェクトでクリッピング」で直上のオブジェクトの形に切り抜けます。
6. タイムライン上部の「＋」で新しいシーン（別のタイムライン）を作り、右クリックの「シーンを追加」で素材として入れ子にできます。グループ制御・時間制御・カメラ制御・部分フィルタ・フレームバッファも右クリックから追加できます。
7. 「保存」で編集ファイル（`.vedproj`）を保存します。次回はこのファイルを画面にドロップすると続きから編集できます（素材ファイルの場所を聞かれたら、素材をもう一度指定してください）。
8. 「書き出し」で MP4 / WebM の動画、WAV の音声、PNG の静止画を書き出します。

主なショートカット：Space 再生/停止、S 分割、Delete 削除、Ctrl+Z / Ctrl+Y 元に戻す/やり直し、Ctrl+S 保存（一覧は「ヘルプ」）。

## 開発

Node.js 22 以上が必要です。

```sh
npm install        # 依存パッケージのインストール
npm run dev        # 開発サーバー（http://localhost:5173/video-editor/）
npm run build      # 本番ビルド（dist/）
npm run lint       # ESLint
npm run typecheck  # 型チェック
npm test           # 単体テスト（Vitest）
npm run test:e2e   # E2E テスト（Playwright）
```

デフォルトブランチへ push すると、GitHub Actions で https://yosshu.github.io/video-editor/ に自動で公開されます。
