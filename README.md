# video-editor

ブラウザだけで動く、レイヤー型の動画編集 Web アプリです。

- 公開 URL：https://yosshu.github.io/video-editor/
- 主な動作環境：PC 版 Chrome / Edge の最新版（Firefox・Safari でも主な機能は動きますが、保存はダウンロード方式になり、使えるコーデックは環境によって異なります）
- 素材はすべてブラウザ内で処理し、サーバーへアップロードしません

## できるようにすること

- 縦に積み重なる **レイヤー** と横方向の **時間** でできたタイムラインに、動画・画像・音声・テキスト・図形を重ねて編集
- オブジェクトごとに位置・拡大率・回転・不透明度などのパラメータ、キーフレームによるアニメーション、エフェクトを設定
- フィルタ・グループ制御・時間制御・カメラ制御などの「制御オブジェクト」で、複数レイヤーにまとめて効果をかける
- 編集内容を **編集ファイル（`.vedproj`）** として保存し、後でブラウザに投下すると続きから編集できる。素材ごと 1 つのファイル（`.vedpack`）にまとめて、別の PC へ持っていくこともできる
- MP4 / WebM（ブラウザのハードウェアエンコーダーを利用）、GIF、連番 PNG、背景が透明な動画で書き出し
- インストールしてオフラインでも使える（PWA）。日本語・英語の表示、ダーク・ライトの配色

## 使い方

1. 動画・画像・音声ファイルを、左の「素材」またはタイムラインにドラッグ＆ドロップします。
2. タイムラインの空いている場所を右クリックすると、テキスト・図形・単色・音声波形などを追加できます。
3. オブジェクトを選ぶと、右の「設定」で位置・大きさ・回転・不透明度・音量などを変更できます。プレビュー上でドラッグして動かしたり、四隅で拡大、上の丸で回転したりもできます。
4. 値の横の ◇ を押すとその時刻にキーフレームが打たれ、別の時刻で値を変えると自動でキーが増えます。「変化」で加速・減速のほか、ランダム・反復・振動も選べます。「中間点を追加」で、動いているすべての値に同じ時刻のキーを打てます。
5. 「設定」の下の「エフェクトを追加」で、ぼかし・縁取り・影・発光・色調補正・クロマキー・ミラー・波打ちなどを重ねられます。音声・動画にはイコライザー・コンプレッサー・エコー・リバーブもかけられます。タイムラインの右クリックから「フィルタ」を置くと、それより上のレイヤー全体にエフェクトがかかります。
6. タイムライン上部の「＋」で新しいシーン（別のタイムライン）を作り、右クリックの「シーンを追加」で素材として入れ子にできます。グループ制御・時間制御・カメラ制御・部分フィルタ・フレームバッファも右クリックから追加できます。
7. 編集を速くする機能：Shift + Delete で削除して後ろを詰める、空いている場所の右クリックで空白を詰める、レイヤー名の右クリックでレイヤーの挿入・削除やまとまりの折りたたみ、M キーでマーカー、「BPM」で曲のテンポに合わせた目盛り、設定パネルの「プリセット…」で設定の保存と再利用。
8. 「保存」で編集ファイル（`.vedproj`）を保存します。次回はこのファイルを画面にドロップすると続きから編集できます（素材ファイルの場所を聞かれたら、素材をもう一度指定してください）。「素材ごと保存」なら素材も 1 つのファイル（`.vedpack`）にまとまり、別の PC でもそのまま開けます。
9. 「書き出し」で MP4 / WebM の動画、GIF、連番 PNG（ZIP）、WAV の音声、PNG の静止画を書き出します。WebM（VP8・VP9）・GIF・連番 PNG は背景を透明にできます。
10. そのほかの機能：
    - GIF・APNG などのアニメーション画像はそのまま動きます。名前に番号の付いた画像は「連番画像…」で 1 本の動画として読み込めます。
    - 字幕ファイル（SRT・WebVTT）をタイムラインにドロップすると、字幕ごとにテキストが並びます。
    - タイムラインの右クリックから「パーティクル」（粒子を飛ばす）を追加できます。
    - 数値の横の「ƒx」で、`sin(time * 2) * 100` や `layer(2, "x")`（別のレイヤーの値）のような式で値を決められます。
    - エフェクト「LUT」で `.cube` ファイルによる色の変換、「シェーダー（自作）」で GLSL による独自の効果を使えます。
    - 音声・動画の「速度を変えても音程を保つ」で、早回し・スロー再生でも声の高さが変わりません。
    - 画面右上で表示の言語（日本語・English）と配色を切り替えられます。ブラウザのメニューからインストールすると、オフラインでも起動でき、`.vedproj` / `.vedpack` をダブルクリックで開けます。

主なショートカット：Space 再生/停止、S 分割、Delete 削除、Shift + Delete 削除して詰める、M マーカー、F 全画面、Ctrl+Z / Ctrl+Y 元に戻す/やり直し、Ctrl+S 保存。一覧と変更は「ショートカット」から。

## 開発

Node.js 22 以上が必要です。

```sh
npm install        # 依存パッケージのインストール
npm run dev        # 開発サーバー（http://localhost:5173/video-editor/）
npm run build      # 本番ビルド（dist/）
npm run lint       # ESLint
npm run typecheck  # 型チェック
npm test           # 単体テスト（Vitest）
npm run test:e2e   # E2E テスト（Playwright）
```

`main` ブランチへ push すると、GitHub Actions で https://yosshu.github.io/video-editor/ に自動で公開されます（作業用のブランチではチェックだけを行います）。
